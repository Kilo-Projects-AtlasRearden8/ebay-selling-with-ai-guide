## How to use it

1. Print this page (or `site/worksheet.html`).
2. Fill in each row as you prep the listing.
3. Use the details in the AI prompts from this manual — swap the bracketed values for your real answers.
4. Paste the final title, description, and policy into eBay.

Keep completed worksheets in a folder so you can look up past sales and prices later.

Next: you're done — start listing!
